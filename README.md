# Mi-primer-app

La primera aplicación que realizamos durante el curso tuvo como objetivo introducirnos a los conceptos básicos del desarrollo de aplicaciones y familiarizarnos con la estructura y funcionamiento de una interfaz interactiva. Para este primer ejercicio se trabajó con elementos sencillos, principalmente un botón, una imagen y un sonido, buscando comprender cómo interactúan entre sí dentro de la aplicación. Al presionar el botón, se generaba una acción que permitía reproducir un sonido, mientras que la imagen funcionaba como parte del diseño visual de la interfaz. Aunque se trató de un proyecto básico, nos permitió conocer el proceso de creación de una aplicación desde sus elementos fundamentales, así como comprender la relación entre los componentes visuales y las acciones que puede realizar el usuario. Este ejercicio sirvió como punto de partida para posteriormente desarrollar aplicaciones con mayor cantidad de elementos e interacciones.
